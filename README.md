# Codwey

Студия готовых сайтов, Telegram-ботов, приложений и Roblox-игр. ИИ-менеджер Вей считает смету в чате.

Сайт: [admin.codway.su](https://admin.codway.su) · домен [codway.su](https://codway.su)

Ключи OpenRouter и оплаты лежат только на VDS, в репозиторий не коммитятся.

## Что куда

| Куда | Что |
|---|---|
| **GitHub `codway`** | Исходники. Pages на `codway.su` |
| **VDS** | Сайт (Node), API (`api.codway.su`), ИИ через Tor |
| **Секреты** | `/root/backend/.env` на сервере, не в git |
